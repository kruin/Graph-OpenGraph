# v4.21.9 — Language Tree FIN half-row

## Change

The Language Tree FIN/V2 surface position is no longer drawn one full grid row below slot1.
That old placement made the finite verb coincide visually with the first DS child row, commonly the NP/VP row under S.

FIN is now drawn on a lexical-axis half-row between slot1 and the first DS child row.

## Result

- slot0 remains one grid row above S.
- slot1 remains on S height.
- FIN/V2 is placed halfway below slot1.
- FIN no longer aligns with the NP node row.
- Ja/nee questions still place the finite verb in the first visible slot row.
