FT input testset

Deze map bevat de geuploade SFG/FG inputgraphs en wordt gebruikt als regressietestset voor:
- thematisch voorstel uit syntactische bomen
- FT Nodes tabel
- per-knoop overrides
- hiërarchische FT-menu's

Runtime-herinnering:
FT Settings > Save schrijft de huidige inputgraphnaam ook naar examples/ft-input-testset/runtime/README-runtime-inputs.txt.
