Demo-viewer

Deze viewer toont JAN/Open Notation als groeiende graph: vrije HOR/VER-plaatsing, optioneel raster, optionele lijnen, en stap-voor-stap afspelen van een JSON-export.

De inhoudelijke voorbeelden staan niet meer als losse viewer-voorbeelden in dit scherm. Gebruik daarvoor de JAN-carousel.

Instellingen

Als JSON echte edges bevat, toont dit die edges. Als edges ontbreken, toont de viewer afgeleide groeilijnen tussen opeenvolgende stappen.

JAN, viewer en carousel

Viewer: speelt één groeiende graph af op basis van JSON. Dit scherm is bedoeld om plaatsing, stappen, raster, lijnen en labels te testen.

Carousel: bevat de uitlegbeelden en didactische voorbeelden van JAN/Open Notation. Gebruik die laag voor introductie, uitleg en vergelijking.

Passend maken tekent opnieuw en past de viewBox aan de zichtbare knopen aan. Dit verandert geen JSON en geen stappen.

JSON laden opent een eigen *_grow_demo.json-bestand, bijvoorbeeld uit OpenGraphEd via Greedy → Export Greedy Grow JSON.

Mobiele bediening

De viewer is een demonstrator. Hij toont hoe open geplaatste knopen stap voor stap kunnen groeien; hij is nog geen volledige editor of les-carrousel.

Tap = volgende stap. Swipe links = volgende. Swipe rechts = vorige. Spatie/Enter = volgende. Backspace/← = vorige. Ctrl+Z = undo. Ctrl+Y = redo. G = play/pause. End/⏭ = static/all. NoLimit gebruikt alle knopen in het JSON-bestand; Auto size koppelt grid, knoopgrootte en labelgrootte automatisch. Standaard toont de viewer HOR/VER-vrije bronknopen zonder verbindingslijnen; zet Lijnen tonen aan voor echte of afgeleide groeilijnen.
