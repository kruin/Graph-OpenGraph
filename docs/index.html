JAN, viewer en carousel

Viewer: speelt één groeiende graph af op basis van JSON. Dit scherm is bedoeld om plaatsing, stappen, raster, lijnen, labels, Greedy-config, browser-generatie, herstel/download en constraint-conflicten te testen.

Carousel: bevat de uitlegbeelden en didactische voorbeelden van JAN/Open Notation. Gebruik die laag voor introductie, uitleg en vergelijking.

Passend maken tekent opnieuw en past de viewBox aan de zichtbare knopen aan. Dit verandert geen JSON en geen stappen.

JSON laden opent een eigen *_grow_demo.json-bestand, bijvoorbeeld uit OpenGraphEd via Greedy → Export Greedy Grow JSON. De viewer leest o.a. greedy, freedom.diagonal_free en constraints.diagonal_free indien aanwezig. Genereer layout maakt daarna in de browser een nieuwe Greedy-plaatsing; Herstel JSON-layout keert terug naar de geladen bron.

Mobiele bediening

De viewer is een demonstrator. Hij toont hoe open geplaatste knopen stap voor stap kunnen groeien; hij kan nu ook een nieuwe Greedy-plaatsing berekenen, maar is nog geen volledige graph-editor.

Tap = volgende stap. Swipe links = volgende. Swipe rechts = vorige. Spatie/Enter = volgende. Backspace/← = vorige. Ctrl+Z = undo. Ctrl+Y = redo. G = play/pause. End/⏭ = static/all. NoLimit gebruikt alle knopen in het JSON-bestand; Auto size koppelt grid, knoopgrootte en labelgrootte automatisch. Standaard toont de viewer HOR/VER-vrije bronknopen zonder verbindingslijnen; zet Lijnen tonen aan voor echte of afgeleide groeilijnen.
