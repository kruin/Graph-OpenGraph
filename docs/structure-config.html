OpenGraph structure-config v4394

Deze HTML-file is de structurele bron voor viewer en voorbeeldeditor. De structure-config bevat géén lexicale woorden zoals hond/man/bijt. Die staan in lexicon-config.html. Bewerk bij voorkeur via structure-editor.html.

Syntax-config

Actieve basisstructuur. Leaves zijn abstracte projectieposities: subject, predicate, object. Voor perfectum kan de structure-editor de VP-regelset vervangen door VP → NP VP en VP → pv VDW.

s:S → np-subj vp
np-subj:NP → subj
subj:{subject} [leaf role=subject source=subject cat=N]
vp:VP → np-obj v
np-obj:NP → obj
obj:{object} [leaf role=object source=object cat=N]
v:V → pred
pred:{predicate} [leaf role=predicate source=predicate cat=V]

Optionele syntax-regelsets

Deze regelset is toegevoegd voor perfectum heeft gebeten. De structure-editor kan hem als actieve syntax-config zetten.

vp:VP → np-obj vp-perfectum
vp-perfectum:VP → pv vdw
pv:{pv} [leaf role=aux source=pv cat=AUX]
vdw:{vdw} [leaf role=participle source=vdw cat=V]

Functional-config

Functionele structuur is n-ary en gebruikt dezelfde abstracte projectiebronnen. Perfectum blijft functioneel hetzelfde: predicaatinhoud projecteert via PRED; de vormelijke splitsing pv/vdw zit in de syntactische/LEX-laag.

ft-clause:CLAUSE → ft-agens ft-pred ft-patiens
ft-agens:AGENS → f-subj
f-subj:{subject} [leaf role=subject source=subject cat=N]
ft-pred:PRED → f-pred
f-pred:{predicate} [leaf role=predicate source=predicate cat=V]
ft-patiens:PATIENS → f-obj
f-obj:{object} [leaf role=object source=object cat=N]

Structurele sources

Dit zijn projectiebronnen/posities, geen lexicale items. Voorbeeld: lexeme=HEEFT projecteert op source=pv; lexeme=GEBETEN projecteert op source=vdw.

subject:{subject} [role=subject cat=N from=syntax+functional]
predicate:{predicate} [role=predicate cat=V from=syntax+functional]
object:{object} [role=object cat=N from=syntax+functional]
pv:{pv} [role=aux cat=AUX from=syntax-perfectum]
vdw:{vdw} [role=participle cat=V from=syntax-perfectum]
